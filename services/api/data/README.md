# Amman Bus timetable snapshot

`ammanbus.json.gz` is a snapshot of the route, stop, and timetable data exposed by the official Vision City Bus web app at <https://online.ammanbus.jo/>.

It is generated by:

```powershell
cd services/api
.venv/Scripts/python.exe scripts/build_ammanbus_data.py
```

The script fetches the public route list and both directions of every route in English and Arabic, then writes one compressed file. It currently contains about 190 routes, 3,800 stops, and 22,000 scheduled departures.

## Use and attribution

The website labels these results **Scheduled** and links to **Amman Bus**. Do not call them live. There is no seat-occupancy or delay feed in this snapshot.

This is an unofficial integration for the prototype. Before a public pilot, confirm data-use permission and attribution requirements with Amman Vision Transport / Kentkart. The upstream endpoints are not a versioned public API and may change without notice.

## Refresh

Re-run the builder and redeploy when routes or timetables change. The snapshot is bundled into the Docker image, so a fresh deploy picks up the new file. The snapshot is intentionally not fetched during a rider request; that keeps planning fast and avoids hammering the operator.
